موقع تعليمي لمقرري **البرمجة 1** و**البرمجة 2** لطلبة المعلوماتية الحيوية والمعلوماتية الصحية في جامعة عمّان العربية.

**مزايا التعلّم**
- **تشغيل بايثون داخل المتصفح** (Pyodide): كل مثال قابل للتشغيل والتعديل دون تثبيت شيء. يُحمَّل المحرك عند أول ضغطة «شغّل» فقط، ويعمل في Web Worker، ويوقف الحلقات اللانهائية بعد 15 ثانية، ويعرض رسوم matplotlib صوراً، ويشرح أشهر الأخطاء بالعربية.
- **تغذية راجعة فورية** في قسم «تدريب»، وكل خطأ يربطك بالدرس الذي تحتاجه.
- **تحليل نقاط الضعف** في صفحة «تقدّمي»: الدروس الأكثر أخطاءً مرتبة.
- **التحفيز**: نقاط، مستويات، أيام متتالية، و10 أوسمة.
- **رمز إتمام موقّع** يرسله الطالب للمدرس، و**شهادة** قابلة للطباعة مع رمز QR للتحقق.
- **إمكانية الوصول**: الوضع الليلي، التباين العالي، ثلاثة أحجام للخط، تنقل كامل بلوحة المفاتيح، دعم قارئات الشاشة.
- **تطبيق ويب قابل للتثبيت (PWA)** يعمل دون إنترنت بعد أول زيارة.

## تعديل المحتوى

1. افتح ملف الوحدة في `content/` وعدّل الدرس (كل درس قاموس بالحقول الاثني عشر).
2. تحقق أن كل الأمثلة تعمل كما هو مكتوب:
   ```bash
   cd content && python verify_all.py
   ```
   يجب أن تنتهي النتيجة بـ «✅ كل شيء سليم».
3. ولّد بيانات الموقع:
   ```bash
   python tools/build_data.py
   ```
   يحدّث هذا أيضاً رقم نسخة `sw.js`، فيحصل الطلبة على المحتوى الجديد تلقائياً.
4. ارفع التغييرات إلى GitHub.

**حقول الدرس الاختيارية المفيدة**
- `bad_out` / `fix_out`: الناتج الخاطئ المتوقع حين يكون الخطأ «خطأ منطقي».
- `stdin` أو `<label>_stdin`: مدخلات `input()` للمثال.
- `good_cmp=False`: لا تقارن الناتج حرفياً (نواتج عشوائية أو عناوين ذاكرة).
- `browser_skip=["good"]`: مثال يعمل على الحاسوب فقط (مثل `venv`)، فلا يظهر له زر «شغّل».

## الإعدادات (`assets/js/config.js`)

| الإعداد | المعنى |
|---|---|
| `lockLessons` | `true`: دروس الوحدة المقفلة لا تُعرض قبل إتقان السابقة. `false`: الدروس مفتوحة للقراءة، والاختبارات وحدها مقفلة |
| `teacherHash` | بصمة كلمة مرور «وضع المدرس» (يفتح كل الوحدات على متصفح المدرس فقط) |
| `author.*` | روابط التذييل؛ اترك أي رابط فارغاً ليختفي |

**تغيير كلمة مرور المدرس** (الحالية: `AAU-Python-2026`):
```bash
python tools/teacher_hash.py "كلمة-المرور-الجديدة"
```
ثم انسخ السطر الناتج مكان `teacherHash` في `config.js`.

> **تنبيه أمني:** الموقع ثابت بالكامل ويعمل على جهاز الطالب. القفل ورمز الإتمام يمنعان الغش العابر، لكنهما ليسا حماية أمنية أمام طالب يقرأ الكود المصدري. الاختبارات الرسمية تُجرى تحت إشراف.

## النشر على GitHub Pages

1. في المستودع `python-mastery` اختر **Add file → Upload files**، واسحب **محتويات** هذا المجلد كلها (وليس المجلد نفسه)، بما فيها المجلدات `assets` و`content` و`tools` والملف المخفي `.nojekyll`.
2. **Commit changes**.
3. **Settings → Pages**: المصدر `Deploy from a branch`، الفرع `main`، المجلد `/ (root)`.
4. بعد دقيقة أو اثنتين يعمل الرابط. تقدّم الطلبة في النسخة الأولى يُنقل تلقائياً (الوحدات المُتقنة والاسم).

## التشغيل محلياً

